# Toolkits

The toolkits in this repository group related reference material, templates, scripts and runbooks into practical capability areas.

## Current Toolkits

- [`IAM Automation Toolkit`](iam/toolkit/README.md)
- [`Microsoft 365 & Graph Toolkit`](microsoft365/toolkit/README.md)
- [`Secure Delivery Toolkit`](secure-delivery/toolkit/README.md)
- [`Incident & Resilience Toolkit`](incident-resilience/toolkit/README.md)

## Toolkit Model

**Reference → Template → Script / Runbook → Evidence → Practical Use**

The objective is to package related knowledge into something another practitioner can understand and use.
