# Definition of Done Template

A delivery item is complete when the agreed business, technical and operational criteria are met.

## Functional
- [ ] Acceptance criteria met
- [ ] Required functionality works
- [ ] Defects within agreed tolerance

## Quality
- [ ] QA completed
- [ ] UAT completed where required
- [ ] Performance acceptable

## Security
- [ ] Security requirements addressed
- [ ] Access controls validated
- [ ] Secrets handled appropriately
- [ ] Logging enabled where required

## Operations
- [ ] Monitoring configured
- [ ] Documentation updated
- [ ] Support model confirmed
- [ ] Runbooks updated
- [ ] Known issues documented

## Release
- [ ] Change/release approval complete
- [ ] Rollback/recovery understood
- [ ] Business owner accepts outcome
