# Operational Acceptance Checklist

## Ownership
- [ ] Business owner identified
- [ ] Service owner identified
- [ ] Technical owner identified
- [ ] Vendor owner identified where applicable

## Support
- [ ] Support model defined
- [ ] Service desk routing defined
- [ ] Escalation path defined
- [ ] Vendor support process documented
- [ ] On-call requirements understood where applicable

## Documentation
- [ ] Architecture documented
- [ ] As-built documentation complete
- [ ] Configuration documented
- [ ] Runbooks available
- [ ] Known issues recorded
- [ ] Integration dependencies documented

## Monitoring
- [ ] Availability monitoring enabled
- [ ] Alerting configured
- [ ] Performance monitoring configured
- [ ] Log access confirmed
- [ ] Alert ownership defined

## Resilience
- [ ] Backup requirements confirmed
- [ ] Recovery process documented
- [ ] Recovery dependencies understood
- [ ] DR requirements confirmed
- [ ] Recovery validation completed where required

## Security
- [ ] Access model reviewed
- [ ] Privileged access controlled
- [ ] Secrets/certificates owned
- [ ] Security logging enabled
- [ ] Vulnerabilities addressed or accepted
- [ ] Data handling requirements confirmed

## Service Management
- [ ] SLA / service expectations documented
- [ ] Change process defined
- [ ] Incident process defined
- [ ] Problem management path understood
- [ ] Capacity/performance expectations understood

## Acceptance
- [ ] Operational team accepts support ownership
- [ ] Material exceptions recorded
- [ ] Residual risks accepted
- [ ] Project handover approved
