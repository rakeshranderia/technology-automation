# Release Readiness Checklist

## Scope
- [ ] Release scope confirmed
- [ ] Requirements traceable
- [ ] Known exclusions documented

## Testing
- [ ] Technical testing complete
- [ ] QA complete
- [ ] UAT complete
- [ ] Critical defects resolved
- [ ] Accepted defects documented

## Security
- [ ] Security requirements addressed
- [ ] Access controls validated
- [ ] Secrets handled appropriately
- [ ] Logging/monitoring enabled
- [ ] Material vulnerabilities addressed or accepted

## Operations
- [ ] Support model ready
- [ ] Monitoring ready
- [ ] Documentation ready
- [ ] Runbooks ready
- [ ] Backup/recovery ready
- [ ] Operational owner accepts service

## Cutover
- [ ] Cutover plan approved
- [ ] Rollback plan approved
- [ ] Business communications ready
- [ ] Vendor resources confirmed
- [ ] Go/no-go authority identified

## Post-Go-Live
- [ ] Hypercare plan defined
- [ ] Known issue register ready
- [ ] Post-implementation review planned where required

## Decision
- [ ] GO
- [ ] NO-GO
- [ ] GO WITH ACCEPTED CONDITIONS
