# 01 — API and Integration Governance

## Simple Explanation

An API is a controlled way for systems to exchange functions or data.

Key questions include:

- who/what is calling;
- what data is exposed;
- what permissions apply;
- how input is validated;
- how traffic is protected;
- how activity is logged.

Useful controls include authentication, authorisation, TLS, least privilege, secrets management, input validation, throttling and monitoring.
