# Back to Basics

Every technology career starts somewhere.

These examples are deliberately simple. They are not intended to demonstrate advanced software engineering or suggest that I spend my days writing production code.

They are here for two reasons:

1. Understanding programming fundamentals helps technology leaders understand the work of technical teams.
2. No GitHub portfolio involving code feels entirely complete without `Hello, World!`

Consider the second requirement satisfied.

---

## The Idea

The same basic concepts are demonstrated in three different languages:

- Python
- PowerShell
- JavaScript

Each example progresses through:

**Hello World → Variables → Arrays → Loops → Conditions → Functions**

The objective is to show how different languages express essentially the same programming concepts.

## From Hello World to Something Useful

The examples in this folder are intentionally basic.

The rest of this repository shows how the same fundamental concepts can become useful technology automation:

- Variables hold configuration or information.
- Arrays allow us to work with collections of systems, users or data.
- Conditions allow automation to make decisions.
- Loops allow the same process to operate across multiple objects.
- Functions make logic reusable.

Eventually:

**Variables + Logic + Loops + Functions**

becomes:

**Automation**

And automation becomes useful when it solves an actual problem.

## A Technology Leadership Perspective

I'm not a software developer, and this portfolio isn't intended to suggest otherwise.

I have, however, spent my career working with developers, engineers, infrastructure specialists, security teams and technology partners.

I believe technology leaders benefit from understanding the fundamentals of the technologies their teams work with.

You don't need to write the production code to understand what the code is doing.

Preferably not in production.
