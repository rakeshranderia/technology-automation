# 02 — IT/OT Integration

## Problem

Manufacturing and operational systems often require ERP, SCADA, PLC and production-system integration without allowing uncontrolled trust between environments.

## Pattern

**Business Need → Data Flow → Boundary → Control → Monitoring → Recovery**

Document interfaces, ownership, downtime impact and vendor dependencies.

## Caveats

Availability and safety can constrain how aggressively traditional IT controls are applied in OT environments.
