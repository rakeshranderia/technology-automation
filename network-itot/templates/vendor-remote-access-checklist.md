# Vendor Remote Access Checklist

- [ ] Business owner identified
- [ ] Vendor identity attributable
- [ ] Access approved
- [ ] Access limited to required systems
- [ ] MFA enabled where supported
- [ ] Privilege minimised
- [ ] Access time-bound where practical
- [ ] Activity logged
- [ ] Session monitoring considered
- [ ] Credential sharing prohibited
- [ ] Access review date defined
- [ ] Removal process defined
