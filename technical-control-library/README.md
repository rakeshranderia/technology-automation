# Technical Control Library

Practical examples for turning governance requirements into repeatable technical controls.

This library is deliberately small. It is not an ISO 27001 implementation guide, certification claim or product catalogue. It shows how common control objectives can be translated into simple operational patterns using tools already present in many Microsoft environments.

## Current module

### Identity & Access Management — simplifying access governance

Focus:

- make access visible;
- make deprovisioning repeatable;
- reduce orphaned permissions;
- preserve an evidence trail;
- use automation to support control owners rather than replace judgement.

See: [`iam/README.md`](iam/README.md)

## Design principle

**Policy says what must happen.  
A technical control makes the expected action repeatable.  
Evidence shows that it happened.**
