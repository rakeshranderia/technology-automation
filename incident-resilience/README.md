# Incident & Resilience

Practical patterns for incident response, disaster recovery, operational resilience and recovery validation.

## Design Pattern

**Detect → Assess → Contain → Communicate → Recover → Validate → Learn**

## Purpose

This module focuses on practical resilience and evidence. It is not a substitute for a formal BCP, crisis-management framework or organisational incident-response plan.
