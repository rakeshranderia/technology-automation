# Azure Change Validation Checklist

## Before Change

- [ ] Correct tenant confirmed
- [ ] Correct subscription confirmed
- [ ] Correct resource group confirmed
- [ ] Target resource confirmed
- [ ] Change approved
- [ ] Dependencies understood
- [ ] Business impact understood
- [ ] Backup/recovery position known
- [ ] Rollback approach defined
- [ ] Monitoring checked
- [ ] No conflicting incident/change identified

## During Change

- [ ] Start time recorded
- [ ] Operator recorded
- [ ] Deployment/change reference captured
- [ ] Errors recorded
- [ ] Unexpected impact assessed before continuing

## After Change

- [ ] Resource health normal
- [ ] Connectivity validated
- [ ] Authentication/access validated
- [ ] Application/service function validated
- [ ] Monitoring normal
- [ ] Security configuration checked
- [ ] Dependencies validated
- [ ] Business validation completed where required

## Closure

- [ ] Evidence retained
- [ ] Documentation updated
- [ ] Exceptions recorded
- [ ] Follow-up actions assigned
- [ ] Change closed
