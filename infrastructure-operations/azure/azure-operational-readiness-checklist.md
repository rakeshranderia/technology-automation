# Azure Operational Readiness Checklist

- [ ] Resource ownership defined
- [ ] Subscription/resource group structure confirmed
- [ ] RBAC reviewed
- [ ] Privileged access controlled
- [ ] Monitoring configured
- [ ] Alerts have owners
- [ ] Logging retained appropriately
- [ ] Backup/recovery requirements defined
- [ ] DR requirements defined
- [ ] Cost owner/budget visibility established
- [ ] Secrets/certificates owned
- [ ] Patch/update responsibility defined
- [ ] Support escalation documented
- [ ] Architecture/as-built documentation available
- [ ] Decommission/lifecycle expectations defined
