# Azure Operational Runbooks

Practical runbook patterns for Azure operations.

These examples focus on repeatability, validation and evidence rather than prescribing a specific Azure architecture.

## Contents

- [`azure-operational-runbook.md`](azure-operational-runbook.md)
- [`azure-change-validation-checklist.md`](azure-change-validation-checklist.md)

## Pattern

**Identify → Validate → Change → Test → Monitor → Evidence**
