# 02 — Directory and File Operations

## Problem

Large file systems are difficult to inspect manually.

## Practical Pattern

Use scripted inventory and controlled file operations to report:

- files/folders;
- modified dates;
- size;
- ownership;
- permissions where appropriate.

## Evidence Produced

CSV exports, migration logs, exception lists and permission reports.

## Caveats

Inventory does not equal classification or ownership. Business context may still be required.
